# ☕ THE VELVET CUP

## Aesthetic 3D Café Web Application – DevOps Project

**The Velvet Cup** is a modern, responsive static café web application
developed to demonstrate the complete DevOps development and deployment
workflow.

The website combines a premium café design with interactive 3D-style
visual effects, animations and JavaScript functionality.

---

## 🌟 Project Overview

The Velvet Cup is a café website where customers can explore:

- ☕ Freshly brewed coffee
- 🥐 Fresh bakery items
- 🍰 Desserts
- 🥑 Café food
- ⭐ Today's specials
- 📖 Our café story
- 🛒 Demo ordering
- 📍 Contact and café information

The project is developed as a **static web application** using:

- HTML5
- CSS3
- JavaScript

The application is then managed using Git and GitHub and
containerized using Docker as part of the DevOps workflow.

---

# ✨ Main Website Features

## 🎨 Premium Café Design

- Modern luxury café interface
- Warm coffee-inspired visual theme
- Responsive layout
- Smooth scrolling
- Glassmorphism navigation
- Animated buttons
- Interactive menu cards

## 🧊 3D Visual Effects

The hero section contains:

- 3D-style **THE VELVET CUP** title
- 3D depth and text shadows
- Animated title highlight
- 3D-style coffee cup
- Floating coffee cup animation
- Animated coffee steam
- Floating particles
- Floating Barista's Choice card
- Mouse-controlled 3D perspective

## ☕ Interactive Menu

The menu supports filtering by:

- All
- Coffee
- Food
- Desserts

## 🛒 Demo Order System

Users can:

1. Enter their name
2. Select a menu item
3. Submit an order
4. Receive an interactive confirmation message

This is a frontend demonstration and does not process
real payments or orders.

## 📱 Responsive Design

The website adapts to:

- Desktop
- Laptop
- Tablet
- Mobile

A responsive mobile navigation menu is also included.
